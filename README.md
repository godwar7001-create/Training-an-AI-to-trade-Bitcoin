# Training-an-AI-to-trade-Bitcoin
Creating and training an AI to trade Bitcoin—currently under development, and the project is open to everyone!
The entire project was generated by AI—specifically, by ChatGPT.
The purpose of the script is to create a number of AI agents that study and learn how to execute the best possible Bitcoin trades.
As this is still an experiment, the agents use virtual money to conduct their trades; as they continue to trade, they refine their skills until they arrive at the best possible trading strategy!

The following image shows the monitor I created to track the progress of the agents. This script is designed solely to read the databases generated by the main script.
When you run the script (Web View.py),
a link will be generated; by entering this link into your web browser, you will gain access to this dashboard:
